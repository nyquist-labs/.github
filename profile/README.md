# Nyquist Labs

**Created and maintained by Anna Lin.** Nyquist Labs is Anna Lin's independent project and is not affiliated with any company or organisation of a similar name.

An open collection of **applied-mathematics and signal-processing projects in electrical engineering**, built around one rule:
every result is predicted from theory *before* it is measured, and the difference is reported and explained.

**Predict → measure → compare → explain**

1. **Predict** — write down the expected number from theory (a formula, a published value, or an explicitly labelled guess).
2. **Measure** — obtain the same number independently: a numerical simulation, an HDL simulator, or a real public dataset.
   *Measured never means a physical lab bench here unless a project says so.*
3. **Compare** — a table of predicted vs measured vs error, with the tolerance that was set in advance.
4. **Explain** — an error analysis of every disagreement, including predictions that turned out wrong.
